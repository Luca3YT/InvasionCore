# 参加者ガイド

配信のマイクラサーバーに入って、一緒に拠点を守ってくれる人向けの説明です。
細かい数値やクラフトレシピまで知りたい人は、最後の「もっと詳しく」を見てください。

---

## どんなゲーム？

拠点の真ん中にある **ネクサス**（ロードストーンのブロック）を、侵略者の大群から守る協力ゲームです。

- 日にちは **7日周期** で進みます。Day 1〜6 は準備期間、**7日目の夜が「血の月」** です。
- 血の月には侵略者が何波も押し寄せます。**夜明けまでネクサスが残れば勝ち** です。
- 侵略者はプレイヤーより **ネクサスを優先して狙い**、行く手の壁を殴って壊します。

勝つたびにネクサスが強くなり、次の血の月はもっと厳しくなります。

---

## 参加のしかた

1. **Minecraft Java Edition 26.2** を用意します（統合版では入れません）。
2. サーバーのアドレスは **配信の中で案内します**。マルチプレイの「サーバーを追加」に入力して接続してください。
3. **サーバーに入った時点で、自動で参加者になります。** コマンドを打つ必要はありません。
4. ルール説明は、配信の概要欄か固定コメントにあります。ゲーム内で `/rule` と打つと URL が表示されます。

---

## ゲームが始まるまで

配信者がネクサスを起動するまでは「待機中」です。待機中は次のようになります。

- **ブロックを壊す・置く、アイテムを拾う・落とす、チェストや作業台を開ける、ボタン・レバー・感圧板などを使う、Mob や動物を攻撃する** ことはできません。
- 体力と満腹度が常に回復するので、死ぬことはありません。
- 画面下に、いまの参加人数とルールの案内が出ます。
- **ネクサスが置かれるまでは、自由に歩き回れます。**
- **ネクサスが置かれると、全員がネクサスのそばへテレポートします。** そこからゲーム開始までは、ネクサスから 48 ブロックより先には進めません（ネザーゲートなども使えません）。境目に近づくと紫の粒が見えます。

ゲームが始まると、チャットに「ゲーム開始！」と出て、これらの制限はすべて解除されます。
ゲームを始められるのは配信者（運営）だけです。

## まずやること

| やること | どうやって |
|---|---|
| 状況を確認する | 画面右のサイドバーに Day・血の月までの日数・**日没と次の Day までの残り時間**・襲撃中の侵略者の数・拠点にいる人数・ネクサスの HP・自分の Shard が出ます。遠出していても、ネザーにいても出ます。残り 1 分を切ると赤い秒数になります |
| お金（Shard）を集める | 侵略者を倒すと **Shard**（アメジストの欠片）を落とします。普通のゾンビやスケルトンなども 1 個落とします（スポナーから出た敵は落としません）。村・廃坑・ネザーやエンドの建物などのチェストにも入っています。地面に落ちた Shard は光っています。拾ってインベントリに入れておくだけで使えます |
| 拠点に戻る | ネクサスは紫に光っていて、壁越しでも見えます。拠点（ネクサスから 48 ブロック）の外にいると、画面下に **ネクサスの方向（矢印）と距離** が出ます。急ぐときは **帰還の羅針盤** を使います（下を見てください） |
| 素材を集める | 準備期間は普通のマイクラと同じです。鉄・レッドストーン・矢・雪玉などがタレットや弾薬になります |
| 配信者の指示を聞く | どこに壁を作るか、誰が何を担当するかは配信者が決めます |

## できること（役割の例）

全員が同じことをするより、分担したほうが守りやすくなります。どの役割でも報酬はちゃんともらえます。

| 役割 | やること | 使うもの |
|---|---|---|
| 前衛 | 壁際やネクサスに張り付いた敵を倒す | 武器・救急キット・閃光弾 |
| 建築・強化 | 壁を作り、強化ハンマーで硬くする | 強化ハンマー・Shard |
| 修理 | 血の月の最中に、削られた壁を直す | 強化ハンマー・応急補修キット |
| タレット係 | タレットを置いて、弾薬を切らさない | 矢・ブレイズパウダー・雪玉・レッドストーン |
| 補給 | 空中投下（補給物資）を拾いに行く、素材を集める | — |

### 強化ハンマーの使い方

ハンマー（鉄の斧の見た目）でブロックを右クリックすると、ブロックが硬くなります。

```
未強化 → 木枠 → 補強木材 → 石積み → 鉄筋コンクリート → 鋼鉄
```

- 1段階ごとに Shard を使います（木枠 3 → … → 鋼鉄 55）。
- 傷んだ強化ブロックを右クリックすると修理になります。
- **スニークしながら右クリック** で、そのブロックの耐久を確認できます。

### 帰還の羅針盤

**右クリックして 7 秒動かずに待つと、どこからでもネクサスのそばへ戻れます。** ネザーやエンドからでも、血の月の最中でも使えます。

- 動いたり、ダメージを受けたりすると中断します（羅針盤は減りません）。
- 使うとなくなります。
- ゲームが始まったときに 1 人 1 個もらえます（あとから入った人も 1 個）。
- ネクサスの画面で **10 Shard** で買えます。作業台で **鉄インゴット 5 個と紙 3 個**（並べ方は自由）でも作れます。

### SHOP

ネクサスの画面の **「SHOP」** で、ガジェット・タレット・罠・弾薬・素材・食べ物を Shard で買えます。
払うのは自分の Shard が先で、足りない分はネクサス内の Shard から払われます。

### 補給物資

ときどき、拠点から少し離れた場所に **補給物資** が空から落ちてきます。チャットに座標が出て、
**光の柱** が立ち、画面下に **補給物資の方向と距離** が出ます。15 分で消えるので、早めに取りに行きましょう。

### ネクサス内の Shard（みんなの共有）

Shard はネクサスに **預けて、みんなで使う** ことができます。

- **Shard を手に持ってネクサスを右クリック** すると、その束を預けられます。ネクサスの画面の「Shard をネクサスに預ける」を押すと、持っている Shard を全部預けます。
- 預けた分は、画面右のサイドバーに **「ネクサス内の Shard」** として表示されます。
- 強化・修理・アップグレードで払うときは、まず自分の Shard を使い、**足りない分が自動でネクサス内の Shard から払われます**。
- 預けた Shard を引き出せるのは配信者（管理者）だけです。

### タレットの使い方

置いたあと、**弾薬を手に持って右クリック** で装填します。弾が切れると止まるので、血の月の前に満タンにしておきましょう。
タレットの上に残りの弾の数が出ています（少なくなると黄色、弾切れで赤）。

| タレット | 弾薬 |
|---|---|
| 射撃 | 矢 |
| 火炎 | ブレイズパウダー |
| 凍結 | 雪玉 |
| 修復 | レッドストーン |

## 血の月の戦い方

- 7日目は昼過ぎ・夕方・日没直前の3回、警告が出ます。日没までに持ち場についてください。
- ネクサスが攻撃されると、どこにいても **画面の真ん中に「ネクサスが攻撃されている！」** と出て、警報が鳴ります。急いで戻ってください。
- Day 1・Day 2 は夜の襲撃も叫喚体も来ません。来るのは弱いゾンビの小さな群れだけです。拠点づくりに使ってください。
- **1 日生き延びるごとに**、夜明けに Shard が 10 個もらえます（2 日ごとにパークポイントも 1 点）。
- 画面上のボスバーに **ウェーブ数・残りの敵・ネクサスの HP** が出ます。
- **5 波目・10 波目にボス** が出ます。ボスごとに必要な対策が違います（壁の厚み・屋根・火力など）。ボスの HP は画面上のボスバーに出ます。
- 攻撃した侵略者は、頭の上に数秒だけ HP（❤ 12/20 のような表示）が出ます。
- **蘇生者（回復役）と守護者（硬くする役）は最優先で倒す** と楽になります。
- 壁に穴が開いたら **緊急バリア** で一時的に塞げます。

### 報酬をもらうために

勝った瞬間（夜明け）に、次の条件を満たしている人に Shard とパークポイントが配られます。

- **サーバーにいる**（どこにいても大丈夫です）
- **生きている**（死んでリスポーン待ちだともらえません）

Shard は、倒した数だけでなく **壁の修理・強化、タレットや罠の設置、攻撃を受け止めた量** でも多くもらえます。

### パーク

血の月を勝つとパークポイントがもらえます。`/invasion perks` で画面を開き、自分を強化できます。
攻撃力・防御力だけでなく、「強化コストが安くなる」「タレットが強くなる」など支援向けのパークもあります。

## 死んでしまったら

どこで死んでも、持ち物は死んだ場所の **墓（自分の頭）** にまとめられます。座標がチャットに出るので取りに行ってください。
墓は **右クリックでも左クリックでも** 回収できます。防具は空いていればそのまま着られます。

- **死んでから 10 分間は、自分しか回収できません。** 10 分を過ぎると、だれでも回収できるようになります。
- 10 分の間に他の人が墓をクリックすると、あなたのチャットに **「許可する」「断る」** のボタンが出ます（60 秒以内に押してください）。
  許可すると、その人があなたの代わりに回収できます。取りに戻れないときは仲間に頼みましょう。
- 墓は回収されるまで消えません。頭の上に、誰の墓か・あと何分で誰でも回収できるかが出ます。

## 参加者のマナー

配信者が別のルールを出している場合は、そちらを優先してください。

- **他の人の建物や拠点を壊さない。** 拠点の壁を作り直すときは配信者に相談してください。
- **ネクサスの報酬は勝手に受け取らない。** ネクサスの「報酬を受け取る」は誰でも押せますが、全部まとめて1人に入ります。配信者の指示で受け取ってください。
- **拠点の近くで大量に採掘しない。** 拠点での採掘・建築・戦闘は「ヒート」として溜まり、溜まりすぎると仲間を呼ぶ叫喚体が出ます。サイドバーの「ヒート」が赤くなったら一度手を止めてください。
- **血の月の最中に勝手に持ち場を離れない。**

## 参加者が使えるコマンド

`/invasion` は `/inv` と短く打てます。

| コマンド | 内容 |
|---|---|
| `/invasion status` | ネクサスの状態と、自分の Shard 所持数（どこからでも見られます） |
| `/rule` | ルール説明の URL を表示する |
| `/bug` | バグ報告・意見のフォームを開く（`/issues` でも同じ） |
| `/patchnote` | 最新のパッチノート（更新情報）を開く |
| `/invasion join` | 防衛に参加する（サーバーに入った時点で自動で参加しているので、普段は不要） |
| `/invasion leave` | 防衛から抜ける |
| `/invasion perks` | パーク画面を開く |
| `/invasion top` | 血の月の踏破ランキング |

## よくある質問

**Q. ブロックが置けない / 壊せない**
A. 稼働中のネクサスは壊せません。それ以外で置けない場合は配信者に伝えてください（サーバーの保護設定の可能性があります）。

**Q. 侵略者を倒したのに Shard が増えない**
A. Shard はアイテムとして落ちます。拾ってインベントリに入れてください。

**Q. 血の月に勝ったのに Shard がもらえなかった**
A. 夜明けの瞬間に死んでいたか、サーバーから抜けていた可能性があります。

**Q. 拠点の場所が分からなくなった**
A. 拠点の外にいれば、画面下に矢印と距離が出ます。矢印の方向に進んでください。ネクサスは紫に光っています。

**Q. 他の人の墓を回収できない**
A. 死んでから 10 分間は本人しか回収できません。クリックすると本人に確認が届くので、許可してもらってください。

**Q. 強化ハンマーが使えない**
A. ネクサスの防衛範囲（48 ブロック以内）でしか使えません。Shard が足りない場合も使えません。

**Q. タレットが撃たない**
A. 弾薬が入っていないかもしれません。素手で右クリックすると残弾が見られます。

## バグ報告・意見を送る

おかしな動きを見つけたときや、「こうなったらいいのに」という意見は、GitHub の Issue から送ってください。
**送るには GitHub のアカウント（無料）が必要です。**

**[報告フォームを開く](https://github.com/Luca3YT/InvasionCore/issues/new/choose)**

| フォーム | こんなとき |
|---|---|
| バグ報告 | 思った通りに動かない・おかしな動きをした |
| バランスの意見 | 強すぎる・弱すぎる・難しすぎると感じた |
| 要望・アイデア | こうなったら面白い・これを追加してほしい |
| 遊び方の質問 | 遊び方やルールがわからない |
| 感想・その他 | 遊んでみた感想、上のどれにも当てはまらない意見 |

- 書いた内容は **誰でも見られます**。本名や住所などの個人情報は書かないでください。
- 送ったあとは、付いている **ラベル** で今どうなっているかがわかります。

| ラベル | 意味 |
|---|---|
| 状態: 確認待ち | まだ開発者が読んでいない |
| 状態: 情報がほしい | 詳しく教えてほしいことがある。コメントを見てください |
| 状態: 確認済み | 開発者が確認した。直す・取り入れる予定 |
| 状態: 対応中 | いま直している・作っている |
| 状態: 次回反映 | 対応済み。次の配信のサーバーから反映される |
| 重複 | 同じ内容の報告がすでにある（そちらで対応します） |
| 見送り | 仕様どおり、または今回は対応しない |
