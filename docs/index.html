INVASIONCORE · 配信参加型

7日目の夜を、みんなで守り抜く。

配信のマイクラサーバーに入って、拠点の中心にある「ネクサス」を侵略者の大群から一緒に守るゲームです。このページでは、参加のしかたと遊び方の基本を説明します。

参加のしかた 詳しい遊び方ガイド

どんなゲーム？

日にちは 7日周期 で進みます。Day 1〜6 は準備期間で、7日目の夜が 血の月 です。血の月には侵略者が何波も押し寄せ、夜明けまでネクサスが残れば勝ち です。

Day 1探索
Day 2壁づくり
Day 3夜に小襲撃
Day 4強化
Day 5弾薬準備
Day 6最終確認
Day 7血の月

侵略者はプレイヤーより ネクサスを優先して狙い、行く手の壁を殴って壊します。勝つたびにネクサスが強くなり、次の血の月はもっと厳しくなります。

参加のしかた

  1. Minecraft Java Edition 26.2 を用意します。統合版では入れません。

  2. サーバーのアドレスは 配信の中で案内します。マルチプレイの「サーバーを追加」に入力して接続してください。

  3. ログインしたら、ネクサス（ロードストーンのブロック）の近くまで行きます。周囲 48 ブロック以内 にいれば自動で参加者になります。

  4. 拠点から離れて探索することが多い人は、ネクサスの近くで次のコマンドを打っておきます。120 ブロック 離れても参加者として扱われます。

    /invasion join

まずやること

やることどうやって
状況を確認する画面右のサイドバーに Day・血の月までの日数・ネクサスの HP・自分の Shard が出ます
お金（Shard）を集める侵略者を倒すと Shard（アメジストの欠片）を落とします。拾ってインベントリに入れておくだけで使えます
素材を集める準備期間は普通のマイクラと同じです。鉄・レッドストーン・矢・雪玉などがタレットや弾薬になります
配信者の指示を聞くどこに壁を作るか、誰が何を担当するかは配信者が決めます

役割の例

全員が同じことをするより、分担したほうが守りやすくなります。どの役割でも報酬はちゃんともらえます。

役割やること使うもの
前衛壁際やネクサスに張り付いた敵を倒す武器・救急キット・閃光弾
建築・強化壁を作り、強化ハンマーで硬くする強化ハンマー・Shard
修理血の月の最中に、削られた壁を直す強化ハンマー・応急補修キット
タレット係タレットを置き、弾薬を切らさない矢・ブレイズパウダー・雪玉・レッドストーン
補給空中投下を拾いに行く、素材を集める—

強化ハンマー

ハンマー（鉄の斧の見た目）でブロックを右クリックすると硬くなります。木枠 → 補強木材 → 石積み → 鉄筋コンクリート → 鋼鉄 の順に上がり、1段階ごとに Shard を使います。傷んだブロックを右クリックすると修理、スニークしながら右クリック で耐久の確認です。

タレット

置いたあと、弾薬を手に持って右クリック で装填します。射撃は矢、火炎はブレイズパウダー、凍結は雪玉、修復はレッドストーンです。素手で右クリックすると残弾が見られます。

血の月の戦い方

7日目は昼過ぎ・夕方・日没直前の3回、警告が出ます。日没までに持ち場についてください。画面上のボスバーに、ウェーブ数・残りの敵・ネクサスの HP が出ます。

  • 5 波目と 10 波目にボスが出るボスごとに必要な対策（壁の厚み・屋根・火力など）が違います。
  • 回復役と強化役から倒す蘇生者（味方を回復）と守護者（味方を硬くする）を残すと、前線が崩れなくなります。
  • 壁に穴が開いたら緊急バリア右クリックした面に、鋼鉄並みの壁を 45 秒だけ張れます。
報酬をもらう条件：勝った瞬間（夜明け）に、次の両方を満たしている人に Shard とパークポイントが配られます。
  • 拠点の近くにいる（48 ブロック以内、/invasion join 済みなら 120 ブロック以内）
  • 生きている（リスポーン待ちだともらえません）

Shard は、倒した数だけでなく 壁の修理・強化、タレットや罠の設置、攻撃を受け止めた量 でも多くもらえます。パークポイントは /invasion perks で使い、自分を強化できます。

死んでしまったら

拠点の近くで死ぬと、持ち物は死んだ場所の 樽（バックパック） にまとめられます。座標がチャットに出るので取りに行ってください。30 分で樽は消え、中身がその場に落ちます。

参加者のマナー

配信者が別のルールを出している場合は、そちらを優先してください。

  • 他の人の建物や拠点を壊さない拠点の壁を作り直すときは配信者に相談してください。
  • ネクサスの報酬は勝手に受け取らない「報酬を受け取る」は誰でも押せますが、全部まとめて1人に入ります。配信者の指示で受け取ってください。
  • 拠点の近くで大量に採掘しない拠点での採掘・建築・戦闘は「ヒート」として溜まり、溜まりすぎると仲間を呼ぶ叫喚体が出ます。サイドバーのヒートが赤くなったら一度手を止めてください。
  • 血の月の最中に勝手に持ち場を離れない抜けるときはチャットで一声かけてください。

参加者が使えるコマンド

/invasion は /inv と短く打てます。

コマンド内容
/invasion status近くのネクサスの状態と、自分の Shard 所持数
/invasion join防衛に参加する（拠点から離れても参加者として扱われる）
/invasion leave防衛から抜ける
/invasion perksパーク画面を開く
/invasion top血の月の踏破ランキング

よくある質問

ブロックが置けない・壊せない

稼働中のネクサスは壊せません。それ以外で置けない場合は配信者に伝えてください（サーバーの保護設定の可能性があります）。

侵略者を倒したのに Shard が増えない

Shard はアイテムとして落ちます。拾ってインベントリに入れてください。

血の月に勝ったのに Shard がもらえなかった

夜明けの瞬間に拠点から離れていたか、死んでいた可能性があります。

強化ハンマーが使えない

ネクサスから 48 ブロック以内でしか使えません。Shard が足りない場合も使えません。

タレットが撃たない

弾薬が入っていないかもしれません。素手で右クリックすると残弾が見られます。
