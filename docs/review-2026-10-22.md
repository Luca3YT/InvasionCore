## 外部サーバー（VPS）で使うための設定

`config.yml` の `web` セクション（変更後はサーバーの再起動が必要）:

```yaml
web:
  enabled: true
  port: 8765            # ホスティングパネルで割り当てた追加ポートにする（Minecraft 本体とは別の番号）
  bind: "0.0.0.0"
  public-url: "http://<サーバーのIPかドメイン>:8765"   # 外から見たアドレス。port と同じ番号にする
  overlay-token: false  # true にするとオーバーレイの URL にもパスワードが付く
```

- ファイアウォールやホスティングパネル（Pelican など）で、`port` の番号を TCP で開ける。
- `/inv admin web` で、外から開ける管理画面・オーバーレイの URL が出る。
- 通信は暗号化されていない（http）。管理画面の URL にはパスワードが入っているので、配信画面に映さない・人に送らない。
- ホスティングパネルのコンソールにも起動時に管理画面の URL が出る。パネルを他の人と共有している場合は、その人にも見える。

## こちらで判断したこと（確認できなかったため）

作業中に確認を取れなかったので、次は安全側か、元の決定を守る形で決めた。変えたい場合は設定で変えられる。

- **オーバーレイのパスワード**: 前回「付けない」と決めた。外部サーバーではインターネットの誰でも URL を開ける状態になるが、
  出るのは名前と Shard の数だけなので、既定は「付けない」のまま。`web.overlay-token: true` で付けられるようにした。
- **ポート**: 既定は 8765 のまま。外部サーバーではパネルで割り当てられた番号に変える必要がある。
- **開始前に使えなくした道具**: 強化ハンマー・応急補修キット・緊急バリア（ブロックを置き換える・置くもの）。
  閃光弾・救急キットは制限していない。

## 実機で確認したこと

- 全エンドポイントが応答し、パスワードが無い・違う場合は 403
- 管理画面での表示パターン切り替えが、開いているオーバーレイに約 2 秒で反映される
- 稼働中に `config.yml` を手で書き換えたあとでパターンを切り替えても、手で書き換えた値が残る
- `/inv setup` に Web サーバーの項目が出る

プレイヤーが必要な確認（Shard 増減の表示、顔、スマホ・配信 PC からの表示）は確認リストにある。

## 直していない気づき（仕様の判断が要るもの）

1回目のレビューから残っているもの:

- 所有者は血の月の最中でも `/invasion stop` → 再起動で、崩壊ペナルティ（Lv-1・再建 Shard）を避けられる。
- 炎心（ボス）の火炎弾は延焼するため、`breach-radius` の外の木造建築も燃えうる。
- 空中投下・バックパックの樽をプレイヤーが壊すと、樽そのものがアイテムとして手に入る（軽微）。
- ネクサスの報酬は、右クリックした人なら誰でも全部受け取れる（視聴者が入る配信では揉める可能性がある）。

今回見つけたもの:

- サーバーに入った人は全員ネクサスのメンバーになるため、参加者として数える範囲が実質 120 ブロックになった。
  GameStage（難易度）と血の月の報酬の分配に、拠点から少し離れて探索している人も含まれる。
- 報酬・引き出しで手持ちが満杯のとき、入り切らない Shard は足元に落ちる。オーバーレイには「報酬 +N」と出たあと、
  落ちた分を拾うと「拾った +k」がもう一度出る（合計は正しいが、同じ Shard が2回表示される）。
- 「今回の貢献度」は血の月の開始と防衛成功でリセットされるので、勝った直後の管理画面では 0 に戻る。
- 管理画面の参加プレイヤーには、これまでにサーバーに入った全員が並ぶ（オンラインの人が先）。配信を重ねると長くなる。
