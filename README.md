# InvasionCore

**侵略MOD（Invasion Mod / ネクサス防衛）× 7 Days to Die（7日周期・拠点強化）** を統合した Paper プラグイン。

ネクサスを設置して起動すると日数が進み始め、**7日ごとの「血の月」に大規模なウェーブ襲撃**が来る。
それまでの準備日で探索・採掘・拠点強化を行い、決戦に備える。

配信のサーバーにみんなで入って、ひとつのネクサスを協力して守る **配信参加型** の企画として使っている。

## ビルド

```bash
./build.cmd package
```

`build.cmd` は JDK 25 以上と Maven を自動検出する（`~/.jdks`・`C:\tools`・Eclipse Adoptium・PATH・
IntelliJ IDEA 同梱の Maven の順。PATH は変更しない）。見つからない場合はリポジトリ直下に
`build.local.cmd`（git 管理外）を作り、`set "JAVA_HOME=..."` と `set "MVN=..."` を書く。
詳しくは [docs/handoff.md](docs/handoff.md) を参照。

成果物: `target/InvasionCore-0.1.0-SNAPSHOT.jar`

## サーバーの起動

**Java 25 の実体を明示的に指定すること。** PATH の `java` が 21 のままだと
`Minecraft 26.1 and newer requires running the server with Java 25 or above` で即座に終了する。

```bash
"<JDK 25 以上>\bin\java.exe" -Xms1G -Xmx2G -Dstdout.encoding=UTF-8 -Dstderr.encoding=UTF-8 -jar paper-26.2-92.jar nogui
```

テスト用のローカルサーバーは `scripts\setup-server.cmd` で `server/`（git 管理外）に作れる。
`server\start.cmd` が最新のプラグイン jar をコピーしてから起動する。詳しくは [docs/handoff.md](docs/handoff.md) を参照。

> **`-Dstdout.encoding=UTF-8` は Windows では必須。** Java 18 以降、`System.out` は
> `file.encoding` ではなくコンソールのコードページを使うため、指定しないと
> 日本語のログとメッセージが全て文字化けする。

## ゲーム開始前（待機中）

ネクサスが無いか未起動の間は待機中になる。サーバーに入った人は自動で参加者になる。
参加はサーバー単位で、どのディメンションにいても参加者として数える（ネクサスはサーバーに1基だけ）。

- ネクサスを置くまでは移動を制限しない（拠点の場所を決める前に皆で下見できるように）
- ネクサスを置いた瞬間、OP（`invasioncore.admin`）以外の全員をネクサスのそばへテレポートする。
  以後は起動するまで、ネクサスから `nexus.defense-radius`（48）ブロックより先へ進めず、ポータルも使えない。
  後から入ってきた人や範囲の外にいる人も、ネクサスのそばへ移す
- OP 以外は、ブロックの破壊・設置（強化ハンマー・補修キット・緊急バリアも含む）、アイテムを拾う・落とす、容器や作業台を開く、ボタン・レバー・感圧板などのレッドストーン部品を動かす、Mob・動物への攻撃ができない
- 全員に再生・満腹度回復（Lv.255）がかかり、死なない
- アクションバーに参加人数とルール案内を表示

ネクサスを起動すると制限が解除される。崩壊しても待機中には戻らない（`/invasion admin end` でネクサスを消すと戻る）。
ネクサスの起動（崩壊後の再建も含む）は OP だけができる。ネクサスの画面の「侵攻を起動する」を一般の参加者が押しても動かない。

## ゲームループ

```
┌─ Day 1〜6 準備フェーズ ────────────────────┐
│ 探索・採掘・素材収集 → 拠点(ネクサス)を強化    │
│  ├ ヒート蓄積 → 叫喚体(Screamer)が襲来       │
│  ├ 徘徊ホードがランダムに通過                │
│  ├ 空中投下（補給物資）                     │
│  └ 夜は小規模襲撃                          │
└──────────────┬───────────────────────┘
               ↓ 7日目の日没
┌─ 血の月 ──────────────────────────────┐
│ 複数ウェーブの総攻撃。5波ごとにボス           │
│  夜明けまで守り抜く → Lv↑ / 報酬 / パークPt   │
│  ネクサスHP 0 → 崩壊（Lv-1・再建に Shard）    │
└───────────────────────────────────────┘
```

## 主な要素

### ネクサス
- `LODESTONE` ベースの設置ブロック。右クリックで GUI。**サーバーに1基だけ** 置ける。
- HP・レベル・アップグレードツリー・報酬バッファを持つ。
- 稼働中は破壊不可。爆発の巻き添えにもならない。
- ネクサス同士は最低 `defense-radius × 2` 離す必要がある。

### GameStage（難易度指標）
```
GameStage = (ネクサスLv × 8 + 生存日数 × 1.5 + 参加者平均Lv × 1.2) × 人数補正
```
敵の数・変異ティア・ボス出現・ルート品質のすべてがこの値を参照する。
人数補正は `sqrt` スケールで、多人数でも1人あたりの負荷が線形に増えないようにしている。

### 侵略Mob（13種＋特殊2種）

| 種別 | 役割 | 解禁 Stage |
|---|---|---|
| 侵略者 (Grunt) | 基本歩兵 | 0 |
| 疾走者 (Runner) | 高速 | 8 |
| 射手 (Ranged) | 遠距離 | 12 |
| 壁蟲 (Crawler) | **壁を登る**。高い壁を無効化 | 14 |
| 掘削者 (Burrower) | 地面を掘って侵入 | 18 |
| 工兵 (Engineer) | 足場を建てて高所突破 | 22 |
| 爆導体 (Bomber) | 壁とタレットを自爆で破壊 | 26 |
| 投擲手 (Lobber) | **質量爆弾を放物線で撃ち込む砲撃型** | 28 |
| 重装体 (Brute) | **超高耐久・ノックバック無効**。一撃が重い | 30 |
| 飛翔体 (Flyer) | 地上防御を無視 | 32 |
| 潜伏体 (Stalker) | **接近するまで不可視**。後衛を刈りに来る | 34 |
| 守護者 (Shielder) | 周囲にダメージ軽減を付与 | 38 |
| 蘇生者 (Necromancer) | **味方を回復**。最優先で潰す相手 | 45 |
| 叫喚体 (Screamer) | ヒート超過で出現し追加ホードを呼ぶ | 特殊 |
| ボス | 5波ごと。下記ロースターから抽選 | 特殊 |

GameStage が上がると下位種別の出現率が段階的に落ち、上位種別に置き換わっていく。

**変異ティア**: 通常 → 凶暴(Feral, Stage24〜) → 汚染(Radiated, Stage60〜・自己再生)

### ボス（5種）

5波ごとに出現。同じ血の月で同じボスは連続しない。

| ボス | 要求されるもの | 解禁 Stage |
|---|---|---|
| 侵略主 (Warlord) | 物量処理。増援召喚・咆哮・鼓舞・突進 | 0 |
| 鉄槌 (Siege Titan) | **壁の厚み**。周囲の壁をまとめて粉砕する | 40 |
| 腐敗の女王 (Blight Queen) | **継続火力**。毒霧・産卵・自己回復 | 55 |
| 炎心 (Emberheart) | **屋根**。飛行して火炎弾を降らせる | 70 |
| 虚空の使者 (Void Herald) | **隊列維持**。瞬間移動と引き寄せ | 90 |

同じ構成の拠点であらゆるボスに勝てないよう、要求される対策を分けてある。

### 独自AI
バニラMobは「近くのプレイヤーを追う」だけなので、防衛対象という概念を独自AIで上書きしている。

- ネクサスを最優先で目指す（プレイヤーは近距離でのみ標的化）
- 経路が塞がれたら**壁を殴って壊す**（壁で完封できない）
- 掘削者は直線的に掘り進む
- 工兵は足場を積んで登り、**侵攻終了時に自動撤去**される
- 破壊範囲は `breach-radius` 内に限定。範囲外の建築物は絶対に壊されない
- 破壊されたブロックは全て記録され `/invasion admin restore` で巻き戻せる

### 防衛設備
**ブロック強化ティア**（強化ハンマーで右クリック）
```
木枠(250) → 補強木材(550) → 石積み(1000) → 鉄筋コンクリート(1900) → 鋼鉄(3600)
```
未強化のバニラブロックも硬度から耐久が導出されるので、土で囲んでも一瞬で抜かれる。

**タレット4系統**（弾薬制）

| 種類 | 効果 | 弾薬 |
|---|---|---|
| 射撃 | 単体ダメージ | 矢 |
| 火炎 | 燃焼＋継続ダメージ | ブレイズパウダー |
| 凍結 | 鈍足化 | 雪玉 |
| 修復 | 味方回復＋強化ブロック修理 | レッドストーン |

**トラップ2種**（経路設計と噛み合わせて使う）

| 種類 | 効果 |
|---|---|
| スパイクトラップ | 上を通る侵略者に継続ダメージ＋鈍足。繰り返し作動 |
| 爆裂地雷 | 踏まれると範囲を吹き飛ばす。使い切り。重装体の足止めに有効 |

地雷はバニラの爆発を使わないので、**自分の拠点が巻き添えで崩れることはない**。

### 消耗ガジェット

ノックバックの効かない重装体や広範囲スキルのボスに対して、押し切られた瞬間を覆すための手札。

| アイテム | 効果 |
|---|---|
| 閃光弾 | 着弾範囲の侵略者を盲目化・鈍足化し、**標的を見失わせる**（ボスにも有効） |
| 救急キット | 自分と周囲の味方を回復 |
| 緊急バリア | クリックした面に3x3の**鋼鉄級の壁**を45秒だけ展開。決壊時の応急処置 |

### ヒートマップ
拠点での活動（採掘・建築・撃破・発砲）が「熱」として蓄積し、閾値を超えると**叫喚体**が湧く。
叫喚体が叫ぶと追加ホードが来るうえ、さらに熱が上がって連鎖する。
準備フェーズが安全な作業時間にならないための仕掛け。
夜間襲撃が始まる日（`cycle.skirmish-start-day`、既定 Day 3）より前は猶予期間で、叫喚体は湧かない。

### 経済・進行
- **Shard（ネクサスの残滓）**: 実アイテム通貨。強化・修理・タレット・再建に使う。
  侵略者のほか、普通の敵（ゾンビ・スケルトンなど）をプレイヤーが倒しても 1 個落とす（`economy.vanilla-mob-shard`。スポナーの敵は対象外）。
- **ネクサス内の Shard**: Shard をネクサスに預けて共有できる（Shard を持って右クリック、または画面のボタンで全部）。
  支払いは手持ちが先で、足りない分がネクサス内から払われる。引き出せるのは管理者だけ。サイドバーに残高を表示。
- **貢献度按分**: 撃破だけでなく**修理・強化・タレット設置・被ダメージ**にも重みがある。40%は頭割り。
- **パーク（10種）**: 血の月踏破でポイント獲得。

| パーク | 効果 |
|---|---|
| 解体屋 | 侵略者への与ダメージ +8%/Lv |
| 重装 | 侵略者からの被ダメージ -6%/Lv |
| 建築士 | 強化・修理コスト -8%/Lv |
| 漁り屋 | Shard 獲得量 +10%/Lv |
| 衛生兵 | 補修キット・救急キットの効果 +25%/Lv |
| 砲手 | タレット・トラップの威力 +8%/Lv |
| 要塞化 | 自分が強化したブロックの耐久 +12%/Lv |
| 弾薬工 | タレットの弾薬を 12%/Lv の確率で消費しない |
| 猛者 | HP半分以下のとき与ダメージ +15%/Lv |
| 遊撃 | 移動速度 +4%/Lv、被弾直後に短時間の加速 |

戦闘系だけを強くすると支援役が報われないため、建築・修理・タレット寄りにも同等の価値を持たせている。
- **ルートステージ**: GameStage に応じて報酬テーブルが4段階で向上。

### ワールドイベント
- 徘徊ホード（準備フェーズ中ランダム。猶予期間はグラントの通常個体 3〜5 体だけ）
- 空中投下（一定間隔・拠点から40〜80ブロック）

### 墓
どこで死んでも、所持品は死んだ場所の **墓（本人の頭）** にまとめられる。右クリックでも左クリックでも回収できる。

- 最初の `grave.owner-only-seconds`（600 秒）は本人だけが回収できる。その後はだれでも回収できる
- 本人だけの期間に他の人がクリックすると、本人のチャットに「許可する / 断る」のボタンが出る
  （`grave.approval-timeout-seconds` = 60 秒で締め切り）。許可されると、その人も回収できる。本人がいなければ断られる
- 墓は回収されるまで消えない。中身は `plugins/InvasionCore/graves.yml` に保存され、再起動しても残る
- 頭の上に「誰の墓か・あと何分で誰でも回収できるか」を表示する
- 素手・爆発・ピストン・エンダーマン・侵略者では壊れない
- 防具は空いていればそのまま着る。入り切らない分は足元に落とす

### ネクサスの案内表示
- ネクサスを光らせ、壁越しにも輪郭が見えるようにする（`guide.nexus-glow`）
- 防衛範囲の外にいる間、アクションバーにネクサスの方向（矢印）と距離を出す。別のディメンションでは座標を出す（`guide.compass`）
- 防衛範囲の境目から `guide.boundary-particles-within`（12）ブロック以内に来ると、境目にパーティクルを描く
- ネクサスが攻撃されると、全員に画面中央の文字・チャット（残り HP）・警告音で知らせる（`nexus.attack-warning-seconds` = 10 秒に1回まで）

## 管理画面・OBS オーバーレイ

プラグインに小さな Web サーバー（既定ポート 8765）が入っている。URL は `/invasion admin web` で表示できる（起動時にもコンソールに出る）。

**外部のサーバー（VPS・ホスティングパネル）で動かす場合**は、`config.yml` の `web.port` をパネルで割り当てた追加ポートにして TCP で開け、
`web.public-url` に `http://<サーバーのIPかドメイン>:<port>` を書いて再起動する。詳しくは [docs/review-2026-10-22.md](docs/review-2026-10-22.md)。

| 画面 | URL | 内容 |
|---|---|---|
| 管理画面 | `<public-url>/admin?token=…` | ネクサスの状態と、参加プレイヤーごとの顔・体力・満腹度・Shard・今回の貢献度・累計戦績・パーク。2 秒ごとに更新。スマホからも開ける。パスワード（token）付き |
| OBS オーバーレイ | `<public-url>/overlay` | ブラウザソース（1920×1080）に入れる。背景は透明で、Shard を拾う・報酬・引き出し・支払い・預けるのたびに右上にカードが出て 5 秒で消える。表示パターン（B ポートレート / C トースト / E ビッグナンバー / F バナー）は管理画面で切り替える |

- 顔はプレイヤーのスキンから切り出して `plugins/InvasionCore/faces/` に保存する（外部の顔画像サービスは使わない）
- パスワードは `plugins/InvasionCore/web.yml` に保存される。消すと次の起動で作り直される
- 開けないときは、サーバー側のファイアウォール（またはパネルのポート割り当て）で `web.port` の TCP を許可する
- `web.overlay-token: true` にするとオーバーレイの URL にもパスワードが付く

### 管理サブコマンド

すべて `invasioncore.admin` 権限が必要。**コンソールからも実行可能**で、その場合は
ネクサス一覧の先頭（`list` の `[0]`）が対象になる。プレイヤーが実行した場合は足元の最寄りが対象。

| サブコマンド | 説明 |
|---|---|
| `web` | 管理画面と OBS オーバーレイの URL を表示（管理画面の URL はパスワード入りなので配信に映さない） |
| `end` | **ゲームを強制終了**。侵略者を消し、ネクサスを中の Shard・報酬ごと撤去する（確認なし） |
| `list` | ネクサス一覧（インデックス・座標・フェーズ・Lv・Day・HP） |
| `create <world> <x> <y> <z>` | コンソールからネクサスを設置 |
| `activate` | 起動。**Shard コストなしで崩壊状態からも復旧できる** |
| `spawn <type> [数]` | 指定種別の侵略Mobを湧かせる |
| `boss <name>` | 指定ボスを出現させる |
| `points <n>` | 自分にパークポイントを付与（通常は血の月踏破でしか入らない） |
| `airdrop` | 補給物資を即座に投下 |
| `forcewave` | 次のウェーブを即座に投入 |
| `setlevel <n>` / `setday <n>` | ネクサスLv / 経過日数を設定 |
| `restore` | 侵略者に壊されたブロックを復元 |
| `despawn` | 侵略者を全て撤去 |
| `reload` | `config.yml` の再読み込み |
| `info` | ネクサス数・稼働数・侵略者数 |

エイリアス: `/inv`

## 設定

すべてのバランス値は `config.yml` に外出ししてある。変更後は `/invasion admin reload`。

主な調整点:
- `cycle.blood-moon-interval` — 血の月の周期（既定 7）
- `nexus.breach-radius` — 破壊が許される範囲
- `gamestage.*` — 難易度カーブ
- `heat.screamer-threshold` — 叫喚体が湧く熱量
- `performance.ai-buckets` — AI更新の分散数（大きいほど軽いが反応が鈍る）
- `nexus.defense-radius` — 防衛範囲。ネクサス設置後〜起動前に動ける範囲も兼ねる（既定 48）
- `grave.*` — 墓（本人だけが回収できる時間、許可の返事を待つ時間）
- `guide.*` — ネクサスの発光・方向表示・境目のパーティクル
- `rules.url` — `/rule` で表示するルール説明の URL
- `web.enabled` / `web.port` / `web.bind` — 管理画面・オーバーレイの Web サーバー（`bind` を `127.0.0.1` にするとこの PC からだけ開ける）
- `web.public-url` — 外から見たアドレス。表示する URL に使う（VPS では必須）
- `web.overlay-token` — オーバーレイにもパスワードを要求するか
- `web.overlay-style` — オーバーレイの表示パターン（`b` / `c` / `e` / `f`。管理画面から変えるとここに保存される）

## パフォーマンス設計

- **AIのバケット分割**: 侵略Mobを UUID ハッシュで N 分割し、1体あたりの AI 更新は N tick に1回。90体でも 1tick あたり約22体しか処理しない。
- **同時出現上限**: `wave.max-alive`（既定90）。押し切られている間は追加投入しない。
- **チャンク保持**: 侵攻中のみネクサス周辺3×3チャンクにプラグインチケットを張り、停止時に解放。
- **強化ブロック記録の掃除**: 5分ごとに実体と食い違った記録を削除。

## 既知の制約

- 空中投下の一時容器はメモリ上でのみ追跡している。サーバー再起動を跨ぐと
  自動撤去の対象から外れ、樽がその場に残る（中身は失われないので実害は少ない）。
- 破壊ブロックの記録もメモリ上のみ。`/invasion admin restore` は**同一セッション内で
  壊されたブロックしか復元できない**。再起動を挟むと記録が失われる。
- 7DTD の「構造耐久（崩落）」「空腹・水分・感染」「トレーダーNPC」は今回スコープ外。
- Folia 系のリージョン別スレッド処理には未対応（通常の Paper スケジューラを使用）。
